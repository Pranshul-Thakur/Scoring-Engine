# Scoring-Engine

This repository contains the complete pipeline for the Kaggle Spoken Grammar Scoring competition. The solution is built in a Colab notebook and uses a two-stage approach to predict a grammar score from 0-5 based on audio files.

## Methodology

This solution treats the problem as a text regression task, not an audio one, as the rubric scores grammatical content.

### Transcription (Audio-to-Text)

- Model: openai/whisper-base
- Process: All 409 training audio files are transcribed into text. This is a one-time, 5-hour process that saves its results to train_with_transcripts.csv.
- Robustness: Uses librosa's robust audio loader to handle malformed/corrupted .wav files in the dataset.

### Regression (Text-to-Score)

- Model: A transformers model (e.g., roberta-base, bert-base-uncased) fine-tuned for regression.
- Training: To prevent overfitting on the small dataset and avoid a leaderboard "shake-up," the model is trained using 5-Fold Cross-Validation.
- Submission: The final submission.csv is generated by taking the ensemble average of the predictions from all 5 models.

## How to Run

1. Setup: Open the .ipynb notebook in Google Colab and set the runtime to use a T4 GPU.
2. Authentication: Run the kagglehub.login() cell to authenticate.
3. Data Download: Run the kagglehub.competition_download() cell to download the data.
4. Run Transcription (One-Time Only): Run the Whisper transcription loop (the 5-hour cell) to create train_with_transcripts.csv.
5. Run Training & Submission:
   - Go to the "Super Reset Cell".
   - Set the BERT_MODEL you wish to test (e.g., "roberta-base").
   - Run the "Super Reset Cell."
   - Run the final K-Fold Training & Submission Loop cell. This will train all 5 models and automatically generate the submission.csv file.
